# RC2014 core for Karabas Go / Mini / Mini G

Work in progress. An [RC2014](https://rc2014.co.uk/) modular Z80 computer with its usual cards (512K ROM / RAM, SIO/2, CF, RTC, CTC, TMS9918A, YM2149) and a built-in VT100 terminal, for the Karabas Go boards. Runs SCM, NASCOM BASIC, RomWBW, CP/M and Fuzix (planned).
